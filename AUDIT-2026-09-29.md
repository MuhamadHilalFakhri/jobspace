# Audit kode JobSpace — 29 September 2026

## Ringkasan

Aplikasi ini adalah aplikasi Next.js App Router dengan React client components, API routes, lapisan services/repository, dan adapter database SQLite/PostgreSQL. Fitur yang terlihat mencakup lowongan, perusahaan, peluang, wawancara, tugas, pengingat, dokumen, halaman/blok, analitik, autentikasi, serta impor/ekspor CSV.

## Hasil tindak lanjut

Seluruh 25 temuan kode di bawah telah ditangani pada source tree. Typecheck dan production build lulus setelah perubahan; test suite tidak dijalankan. Dependency tree sudah dipasang ulang dengan PostCSS 8.5.28 dan npm install melaporkan nol kerentanan.

Server Neon MCP resmi sudah dikonfigurasi untuk proyek Codex melalui OAuth di .codex/config.toml; konfigurasi tidak menyimpan API key. Plugin sudah terhubung ke project Job Tracker dan branch production. Skema JobSpace lolos validasi di branch sementara dan sudah diterapkan ke production setelah persetujuan pengguna: 24 tabel aplikasi terdeteksi, tanpa user aplikasi; tabel Neon Auth tetap ada. Password role neondb_owner yang sebelumnya terekspos sudah dirotasi dan pooler transaction aktif. Seluruh ikon antarmuka kini memakai Meya Icons 1.0.4 (MIT); Lucide dihapus dan pemindaian source/seed tidak menemukan emotikon tersisa. Typecheck lulus. DATABASE_URL (pooled untuk aplikasi) serta DATABASE_URL_UNPOOLED (direct untuk migrasi) sudah disimpan di .env.local; file ini dicakup aturan .gitignore. npm run db:migrate berhasil dan melaporkan skema mutakhir. Koneksi pooled berhasil diuji dengan konfigurasi TLS aplikasi. Verifikasi production mengonfirmasi 24 tabel public, dua versi ledger (000_baseline dan 001_neon_hardening), constraint pages_parent_user_fk, serta sembilan tabel Neon Auth.

Cakupan: seluruh 97 file proyek yang terinventarisasi di bawah ditinjau statis. Peninjauan meliputi keterkaitan UI/API/service/schema, alur auth dan ownership, query database, validasi, serta konfigurasi dependensi. npm audit dijalankan terhadap lockfile.

Temuan di bawah adalah snapshot sebelum remediasi; status terkininya tercatat pada Hasil tindak lanjut. Snapshot awal mencatat: secret sesi punya fallback publik, kredensial demo tertanam dan seed dapat menghapus data, verifikasi sertifikat TLS dapat dimatikan, parameter pencarian SQLite keliru, upload dibuffer sebelum batas ukuran, dan ada masalah ownership pada parent halaman. Ada pula kontrak API/UI yang membuat fitur wawancara tidak berfungsi.

Pada audit awal, build/typecheck/test belum dijalankan; tindak lanjut menjalankan typecheck dan production build, keduanya lulus. Test suite tidak dijalankan. Data pribadi dalam .env.local serta isi database lokal sengaja tidak dibuka. Folder hasil build dan vendor seperti .next serta node_modules tidak termasuk cakupan source review.

## Temuan

### P1 — Perbaiki sebelum penggunaan produksi

1. **Secret autentikasi memiliki fallback publik.**  
   Lokasi: src/lib/auth.ts:16-20. Saat AUTH_SECRET kosong, aplikasi menandatangani sesi memakai nilai tetap yang diketahui publik. Jika lupa mengatur env di produksi, pemalsuan sesi menjadi mungkin. Tolak startup produksi bila secret tidak tersedia dan validasi panjang/entropinya; jangan gunakan fallback.

2. **Akun demo dan seed dapat membuka atau menghapus data.**  
   Lokasi: src/components/LoginForm.tsx:10-11,143-149; scripts/seed.mjs:4,22-24,35-50. Form login mengisi demo@jobspace.local/password123. Seed memakai kredensial yang sama, lalu menghapus pekerjaan, perusahaan, peluang, template, halaman, dan tugas milik akun tersebut sebelum mengisi ulang. Pengguna luar dapat menebak kredensial; menjalankan seed ke database produksi dapat menghapus data akun demo. Pisahkan seed lokal, blokir seed pada environment produksi, dan hilangkan kredensial demo dari UI produksi.

3. **Verifikasi sertifikat TLS PostgreSQL dimatikan.**  
   Lokasi: src/lib/data/db.ts:154-164; scripts/migrate.mjs:17-23. Opsi rejectUnauthorized:false menerima sertifikat server yang tidak tervalidasi pada koneksi yang masuk kondisi tersebut. Ini membuka risiko koneksi database disadap melalui server perantara. Pertahankan verifikasi sertifikat dan gunakan CA/konfigurasi TLS yang benar.

4. **Pencarian lowongan rusak pada SQLite.**  
   Lokasi: src/lib/data/jobs.repo.ts:120-125; src/lib/data/db.ts:30-33. Query memakai placeholder PostgreSQL yang sama tiga kali untuk company, position, dan notes dengan satu nilai. Adapter SQLite mengubah setiap $n menjadi ?, sehingga query meminta lebih banyak binding daripada parameter yang dikirim. Cari lowongan dengan filter kata kunci gagal pada mode SQLite. Pertahankan placeholder bernomor SQLite (?1) atau kirim tiga nilai yang sama.

5. **Daftar wawancara membaca nama field yang salah.**  
   Lokasi: src/lib/services/jobs.service.ts:571-593; src/components/InterviewsClient.tsx:18-29,120-126,347-350. Service/API menghasilkan scheduledDate, scheduledTime, dan locationOrLink; UI membaca scheduled_date, scheduled_time, dan location_or_link. Filter tanggal memakai undefined sehingga wawancara tidak masuk daftar mendatang/lampau, dan tanggal/lokasi tidak tampil. Samakan kontrak tipe dan respons API.

6. **Parent halaman tidak dibatasi pada pemilik yang sama.**  
   Lokasi: src/app/api/pages/route.ts:26-31; src/lib/services/jobs.service.ts:861-871; db/schema.sql dan db/schema.sqlite.sql pada pages.parent_id. Endpoint memeriksa format parentId tetapi service tidak memastikan parent milik user yang sedang login. Pengguna dapat membuat child pada halaman pengguna lain; penghapusan parent dapat menghapus child lintas akun karena ON DELETE CASCADE. Validasi ownership parent dalam transaksi dan cegah referensi lintas user di tingkat penyimpanan.

7. **Log error SQLite merekam parameter query mentah.**  
   Lokasi: src/lib/data/db.ts:61-72. Param dapat berisi email, hash password, catatan pencarian kerja, kontak perekrut, atau konten pengguna. Hindari mencatat nilai param; log kode query/error teredaksi dan ID korelasi saja.

8. **Batas ukuran dokumen diberlakukan setelah seluruh berkas dibaca ke memori.**  
   Lokasi: src/app/api/documents/route.ts:22-39; src/lib/services/documents.service.ts:52-56. Route memanggil formData() dan arrayBuffer() sebelum service memeriksa batas 8 MB. CSV import juga membaca seluruh file tanpa batas ukuran/jumlah baris di src/app/api/import/route.ts:13-20. Pengguna terautentikasi dapat mengirim payload besar dan menghabiskan memori/CPU. Terapkan batas body saat request masuk, gunakan parsing/stream dengan batas, dan batasi jumlah baris impor.

### P2 — Perbaiki untuk mencegah data hilang atau fitur salah

9. **Peluang kerja tidak menyimpan salary yang diisi.**  
   Lokasi: src/components/OpportunitiesClient.tsx:17-29,74-82; src/app/api/opportunities/route.ts; src/lib/services/jobs.service.ts:720-763. UI mengirim salary, sedangkan schema/service menerima salaryRange. Nilai dibuang sehingga gaji hilang saat disimpan. Samakan nama field di form, API, dan model.

10. **Fallback konversi peluang dapat membuat duplikasi.**  
    Lokasi: src/components/OpportunitiesClient.tsx:98-123. Catch fallback menangani semua kegagalan endpoint konversi, termasuk kegagalan jaringan setelah konversi sebenarnya berhasil, lalu membuat job kedua dan menghapus peluang. Batasi fallback pada error yang memang aman dicoba ulang atau gunakan idempotency key; samakan status hasil konversi server/fallback.

11. **Field tanggal arsip tidak cocok dengan respons API.**  
    Lokasi: src/lib/data/jobs.repo.ts:26-70; src/components/ArchiveClient.tsx:9-16,115-120. API memetakan appliedAt/deletedAt, sedangkan UI mengharapkan applied_at/deleted_at. Tanggal arsip tidak dirender dengan benar. Samakan kontrak data.

12. **Tugas tanpa tanggal tidak dapat ditemukan dari UI.**  
    Lokasi: src/components/TasksClient.tsx:47,72-77,108-115. Form membolehkan dueDate kosong, tetapi view today/overdue/upcoming mengecualikan tugas yang due_date-nya null dan tidak ada view semua tugas. Tugas Todo tanpa tanggal tersimpan tetapi tidak dapat dibuka lagi untuk diselesaikan. Tambahkan view tanpa tanggal/semua atau wajibkan tanggal.

13. **Perusahaan tidak terhubung ke lowongan dan LinkedIn terbuang.**  
    Lokasi: src/components/CompaniesClient.tsx:49-55; src/app/api/companies/route.ts:14-20; src/lib/services/jobs.service.ts pada create/list company; src/lib/data/jobs.repo.ts:199-229. Form mengirim linkedin tetapi schema/service tidak menyimpannya; hitungan application_count bergantung pada jobs.company_id, sedangkan pembuatan lowongan tidak mengisi company_id. Akibatnya field LinkedIn hilang dan hitungan aplikasi tidak akurat. Simpan field dan hubungkan lowongan ke entitas perusahaan.

14. **Tombol status lowongan tidak punya kontrol visual yang dapat diklik.**  
    Lokasi: src/components/ApplicationsClient.tsx:266-277. Select status diberi sr-only dan tidak ada tombol/overlay yang tampak untuk mengubah status dengan mouse. Pengguna keyboard masih dapat mencapai kontrol tersembunyi, tetapi pengguna mouse tidak melihat affordance-nya. Tampilkan kontrol status yang terlihat dan berlabel.

15. **Validasi format tanggal/waktu menerima nilai mustahil.**  
    Lokasi: src/lib/domain/validation.ts:16-18,91-109; src/app/api/tasks/[id]/route.ts:10-19. Regex hanya memeriksa bentuk YYYY-MM-DD/HH:MM, bukan kalender atau rentang jam; endpoint update task menerima status string bebas dan dueDate string yang hanya dibatasi panjang. Data invalid dapat tersimpan di SQLite atau menjadi error constraint di PostgreSQL. Validasi tanggal kalender, jam 00:00-23:59, enum status, dan aturan rentang di boundary API.

16. **Menghapus deadline tidak menonaktifkan pengingat lama.**  
    Lokasi: src/lib/services/jobs.service.ts:174-179. Saat deadline di-clear, tidak ada reminder aktif yang dibatalkan. Selain itu, upsert pengingat follow-up di src/lib/data/jobs.repo.ts:451-467 menganggap reminder yang telah selesai sebagai reminder yang sudah ada dan tidak membuat pengingat aktif baru. Sinkronkan reminder saat deadline/status berubah dan cari reminder aktif saja.

17. **Respons lama dapat mengganti timestamp respons terbaru.**  
    Lokasi: src/lib/data/jobs.repo.ts:403-409. Komunikasi masuk yang diimpor/backfill selalu menimpa last_response_at tanpa mengambil tanggal terbaru. Menambahkan balasan lama dapat membuat status/pengingat follow-up keliru. Simpan maksimum tanggal respons.

18. **Ekspor CSV rentan formula injection.**  
    Lokasi: src/lib/services/documents.service.ts:243-247; src/lib/csv.ts:60-72. Pengutipan karakter CSV tidak menetralkan sel yang diawali =, +, -, atau @. Membuka ekspor yang memuat teks pengguna di spreadsheet dapat mengeksekusi formula. Netralisasi karakter pemicu spreadsheet sebelum escaping CSV.

19. **File dokumen dapat tertinggal di disk.**  
    Lokasi: src/lib/services/documents.service.ts:52-106,201-208. Berkas ditulis sebelum transaksi metadata, sehingga kegagalan insert meninggalkan file yatim. Penghapusan hanya menandai metadata, tanpa membersihkan berkas. Tambahkan cleanup saat transaksi gagal dan kebijakan retensi/penghapusan file yang jelas.

20. **Migrasi tidak mengubah tabel yang sudah ada dan schema SQLite/PostgreSQL berbeda.**  
    Lokasi: db/schema.sql; db/schema.sqlite.sql; src/lib/data/db.ts pada inisialisasi SQLite; scripts/migrate.mjs. CREATE TABLE IF NOT EXISTS tidak menerapkan ALTER pada database lama, dan tidak ada migration versioning. Skema juga berbeda: PostgreSQL punya unique index nama perusahaan aktif dan beberapa CHECK yang tidak setara di SQLite. Database yang sudah dipakai bisa tertinggal atau berperilaku berbeda antar driver. Tambahkan migrasi bernomor dan samakan constraint/index kedua skema.

21. **Rate limiting login/registrasi belum ada.**  
    Lokasi: src/app/api/auth/login/route.ts:13-47; src/app/api/auth/register/route.ts. Login menerima percobaan tanpa pembatasan; respons/timing juga dapat membantu enumerasi email. Tambahkan throttling per akun/IP, respons yang seragam, dan perlindungan brute force.

22. **Dashboard menghitung hanya halaman pertama dan menyimpan catatan lintas akun.**  
    Lokasi: src/components/HomePage.tsx:74,89-104,264-269. Dashboard meminta maksimal 100 job lalu menghitung dari hasil tersebut; angka menjadi kurang dari total saat job lebih banyak. Catatan disimpan pada satu localStorage key untuk semua pengguna browser, dan menghapus teks kosong tidak menimpa nilai lama. Tombol Tandai selesai hanya menuju halaman pengingat, tidak menyelesaikannya. Gunakan endpoint aggregate, key per akun, simpan nilai kosong, dan arahkan tombol ke aksi penyelesaian nyata.

23. **Halaman perusahaan dari Command Palette menuju route yang tidak tersedia.**  
    Lokasi: src/components/CommandPalette.tsx:155-162; src/app/companies/page.tsx. Navigasi ke /companies/{id}, tetapi hanya route /companies yang ada. Hasil pencarian perusahaan berakhir 404. Buat halaman detail atau arahkan ke halaman daftar dengan pemilihan perusahaan.

24. **Ikon halaman tidak tersimpan bila judul tidak berubah.**  
    Lokasi: src/components/PageEditor.tsx:58-87,124-140. Perubahan ikon dikirim bersama rename; handler berhenti jika judul tidak berubah, sedangkan tombol Save menyimpan blocks saja. Simpan title/icon melalui handler terpisah atau satu operasi halaman.

25. **Statistik dihitung dua kali dengan aturan berbeda.**  
    Lokasi: src/lib/services/jobs.service.ts:383-498; src/lib/domain/stats.ts. Endpoint menghitung metrik sendiri dan fungsi domain lain diuji terpisah. Pembilang balasan/wawancara dapat mencakup job Draft sedangkan penyebut mengeluarkan Draft, sehingga rasio dapat melewati 100%. Satukan perhitungan dan definisikan populasi pembilang/penyebut.

## Catatan cakupan

Daftar source/config berisi 97 file: 80 di bawah src, 3 skema/migrasi, 2 scripts, 2 tests, dan 10 root/config. Isi .env.local dan database lokal tidak dibaca karena berpotensi berisi data/secret. node_modules, .next, serta keluaran build/cache termasuk tsconfig.tsbuildinfo dikecualikan. Typecheck dan production build lulus setelah remediasi; test suite tidak dijalankan. Neon MCP aktif pada project Job Tracker; skema berhasil diterapkan dan diverifikasi di production. Password database sudah dirotasi, pooler aktif, URL aplikasi dan migrasi tersimpan secara lokal, koneksi pooled teruji, dan migrasi direct telah dijalankan ulang tanpa perubahan tertunda.
